# 原始問題與後續改進

本專案承接 108 學年度第一學期「機器人感知估測」期末專案。原程式以 ScanData、EKF_track、j_mini 與主節點組成感知、估測與控制流程；本版保留這個功能架構，重新整理介面及運算。以下是現存課程程式快照的問題與後續修正，不用來推定當年所有展示版本的表現。

| 原始問題 | 本版改進 | 驗證方式 |
|---|---|---|
| 分類輸出將特徵 5、6 當作座標 | Detection 獨立存放區段質心與分類分數 | 已知質心單元測試 |
| 固定讀取 720 點，邊界先讀後檢查 | 按 ranges 長度遍歷，先驗證有效性 | 0／360／720／1080 點及無效值測試 |
| 特徵均值未除點數，角度固定索引，退化除法 | 中心化計算、atan2 轉角、QR 圓擬合與退化分支 | 圓形、共線、重複點與非有限值測試 |
| MATLAB 與 C++ 特徵定義不完全一致 | 訓練與推論共用同一 C++ 特徵函式 | 匯出歷史特徵並重新訓練 |
| 小機率連乘下溢 | log-likelihood 累加；非負特徵 log1p 變換 | 極小變異數與大特徵測試 |
| 無條件選最近量測 | 先預測，再以 Mahalanobis distance 門檻關聯 | 離群候選與空候選測試 |
| Kalman gain／covariance 公式不一致 | 線性 KF、LDLT 求解、Joseph 更新 | 解析解與 5,000 步協方差測試 |
| 模型與 Timer 的 dt 不一致 | 掃描時間差決定狀態轉移及過程噪聲 | 不同 dt、重複與倒序時間戳 |
| 無量測以零座標代替 | Empty／Tentative／Tracking／Coasting／Lost | 確認、遮擋、遺失與重取測試 |
| 多幀累積與不正確陣列釋放 | RAII 容器，核心僅保存當前估計 | AddressSanitizer／UBSan 與長序列測試 |
| 重複計算區段特徵 | 每個候選區段計算一次並傳遞結果 | 完整流程回放與效能量測 |
| 控制未完整處理資料失效 | 不新鮮、缺測、TF 失效、障礙近距離皆輸出零速度 | 單元測試及 ROS 整合測試 |

第一版只追蹤單一腿部候選。沒有雙腿身份配對、多人重識別、完整導航規劃或強化學習；另一學期的 Q-learning 專案不混入本專案。

## 固定設定

分段 gap 0.09 m、最少 3 點；Mahalanobis squared-distance 門檻 9.21；初次目標選取限於 tracking frame 原點 3 m 內；連續 3 次匹配確認；缺測 0.6 s 後遺失。初次選取的範圍以 odom 原點計，適用於起點附近 demo，長距離移動部署需改為相對底盤的選取範圍。

過程加速度標準差 0.8 m/s²，位置量測標準差 0.1 m。控制距離 0.8 m、死區 0.05 m、線速度上限 0.25 m/s、角速度上限 0.8 rad/s、加速度限制 0.5 m/s² 與 1.5 rad/s²。停止條件立即覆寫速度，優先於平滑限制。

這些是可重現的實驗設定，不是經實機辨識得到的底盤參數。相關常數集中在各模組，不宣稱已提供完整動態調參介面。
